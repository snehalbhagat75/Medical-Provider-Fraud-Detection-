# Medical-Provider-Fraud-Detection

📌 Project Overview

This project focuses on analyzing healthcare claims data to identify potentially fraudulent or high-risk medical providers. The analysis uses provider, beneficiary, inpatient, and outpatient claim data to identify unusual claim patterns and high-cost claim behavior.

Interactive dashboards were developed in Power BI to analyze provider activity, claim trends, reimbursement amounts, and provider risk indicators.

🎯 Objectives
Analyze healthcare provider and beneficiary data.
Compare inpatient and outpatient claims.
Identify providers with high claim amounts.
Analyze high-cost claim patterns.
Calculate provider-level risk indicators.
Identify potentially high-risk providers.
Build interactive dashboards for fraud and risk analysis.
