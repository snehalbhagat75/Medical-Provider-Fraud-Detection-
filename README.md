# 🏥 Medical Provider Fraud Detection

## 📌 Project Overview

This project analyzes healthcare claims data to identify potentially fraudulent and high-risk medical providers. The analysis focuses on provider claim behavior, reimbursement patterns, inpatient and outpatient claims, and provider-level risk indicators.

The project uses SQL, Power BI, Power Query, and DAX to transform healthcare data into meaningful insights and interactive dashboards.

---

## 🎯 Objectives

- Analyze healthcare provider and beneficiary data.
- Compare inpatient and outpatient claims.
- Identify providers with high claim volumes and reimbursement amounts.
- Analyze high-cost claim patterns.
- Calculate provider-level risk indicators.
- Identify potentially high-risk providers.
- Build interactive Power BI dashboards for data analysis.

---

## 📊 Dashboard Features

The Power BI dashboard includes the following key metrics and analyses:

- Total Providers
- Total Claims
- Total Inpatient Claims
- Total Outpatient Claims
- Total Reimbursement Amount
- Average Claim Amount
- Claim Trend Analysis
- Inpatient vs Outpatient Claim Comparison
- Top Providers by Reimbursement
- High-Cost Claims Analysis
- Provider Risk Analysis
- Provider Risk Ranking
